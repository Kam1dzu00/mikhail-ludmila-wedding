## RSVP

Для доставки используется бесплатный сервис FormSubmit:

`https://formsubmit.co/ajax/kam1dzu00@yandex.ru`

Перед началом работы адрес нужно активировать один раз:

1. Отправить тестовый ответ через опубликованный сайт.
2. Открыть письмо от FormSubmit на `kam1dzu00@yandex.ru`.
3. Нажать кнопку подтверждения адреса.
4. После активации все новые ответы гостей будут приходить на эту почту.

Письмо содержит имя гостя, присутствие, выбранные мероприятия, количество людей
и комментарий.
